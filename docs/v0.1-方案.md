## 一、定位（一句话）

**给我自己用的 Windows 桌面番茄钟：按下去、好看、到点一定叫醒我、事后能看清时间去哪了。**

不做通用产品，不冲榜，不收费。判断标准只有一条：**我自己愿不愿意每天开着它。**

用户原话：自用、先把番茄钟做出来、好看一点、后续可能加小功能、技术栈我来定。

## 二、技术栈决策

### 已确认的本机环境

- Node v24.13.0（`C:\Program Files\nodejs\node.exe`）
- pnpm 11.21.0
- git 2.49.0
- **cargo 未安装**

### 选定：Electron + Vite + React + TypeScript

| 选择 | 为什么 |
|---|---|
| **Electron**（不用 Tauri） | Tauri 要 Rust 工具链 + VS Build Tools + WebView2，本机 cargo 都没有，装齐成本远大于收益；Electron 只要 Node，今天就能跑起来。自用场景不在乎 150 MB 包体积，在乎的是"今晚能不能用上"。 |
| **Vite** | 热更新快，改样式立刻看到——"好看"这件事必须能快速试。 |
| **React + TypeScript** | 组件化方便后续加"小功能"；TS 防止改到后面自己看不懂。 |
| **CSS 变量 + 手写样式** | 不引 Tailwind/组件库。自用项目最怕样式被框架绑死，"好看"要能随心改。 |
| **JSON 文件存储**（v0.1） | 见下方说明。 |
| **electron-builder** | 打单文件安装包 + 免安装 zip，两样都要。 |

### 一个刻意的偏离：v0.1 不用 SQLite

调研里我写的是"本地 SQLite"，实际落地改成 **JSON 文件 + 原子写入**，理由：

- `better-sqlite3` 是原生模块，在 Electron 里要跑 `electron-rebuild`，是本项目最可能卡住一整天的地方；
- v0.1 的数据量（一天几十条记录）JSON 完全够，一年也就几百 KB；
- 关键做法：**数据访问统一走 `src/main/store/` 一个仓储层**，界面和业务只调 `listSessions()` / `addSession()` 这类方法，不碰文件路径。以后要换 SQLite 只改这一层，其他代码不用动。

这是有意的取舍，不是偷懒。

## 五、"好看"的具体标准（这是需求，不是形容词）

用户明确要求好看，所以必须落成可验收的规范。

### 基调

深色为默认，安静、克制、有一点点温度。不要"仪表盘感"，不要渐变彩虹，不要玻璃拟态堆料。

### 颜色（写进 `tokens.css`，只在这里改）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0E1013` | 窗口底色 |
| `--surface` | `#171A1F` | 卡片/浮层 |
| `--line` | `#24282F` | 分隔线、描边 |
| `--ink` | `#EDEFF2` | 主文字 |
| `--ink-2` | `#9AA1AC` | 次要文字 |
| `--accent` | `#FF6B57` | 专注态主色（番茄红） |
| `--break` | `#4FD1A5` | 休息态主色 |
| `--warn` | `#F5B942` | 被打断/超时 |

专注时整体用 `--accent`，休息时整体切 `--break`——**换阶段要换整个界面的色调**，这是最容易做出"高级感"的一招。

### 字体与数字

- 界面文字：`system-ui, "Segoe UI", "Microsoft YaHei"`。
- 大数字：等宽数字 `font-variant-numeric: tabular-nums`，字号 88–96px，字重 200–300，字间距 `-0.02em`。**数字跳动时不能左右抖**（等宽数字就是为了这个）。

### 动效

- 时长 150–250ms，`cubic-bezier(.4,0,.2,1)`；只动 `transform` / `opacity`。
- 圆环进度用 `stroke-dashoffset` 过渡，跟真实时间连续走，不要一秒一跳。
- 开始计时那一刻：圆环从当前值轻微"呼吸"一次，作为仪式感。
- 结束提醒的闪烁：窗口边框 3 次 600ms 的呼吸，不做全屏频闪（刺眼）。

### 布局

- 主界面：一个居中的圆环（直径约 320px），环内大数字 + 阶段标签，环下方一排三个按钮（首键兼开始与暂停，另两个是跳过、重置），底部一行小字显示"今天第几个番茄 / 累计专注时长"。
- 最小窗口 420×520，默认 480×620；不缩放字号，窗口小就留白少。
- 统计页用同一套色和间距，图表只用 `--accent` / `--line` / `--ink-2` 三色，不引入新颜色。

### 验收方式（避免自嗨）

做完后让用户看一眼主界面截图，问一句"行不行"。**视觉由用户拍板，不由开发自己判断。** 先给静态稿，再动画。

## 六、数据模型

```ts
// 设置
type Settings = {
  focusMin: number;        // 默认 25
  shortBreakMin: number;   // 默认 5
  longBreakMin: number;    // 默认 15
  roundsBeforeLong: number;// 默认 4
  autoStartNext: boolean;  // 默认 false（自用先不自动，避免被迫开始）
  soundOn: boolean;
  volume: number;          // 0-1
  launchAtLogin: boolean;
  window: { x?: number; y?: number; w: number; h: number };
};

// 一条专注记录
type Session = {
  id: string;              // uuid
  kind: 'focus' | 'short' | 'long';
  startedAt: string;       // ISO
  endedAt: string;         // ISO
  plannedSec: number;      // 计划时长
  actualSec: number;       // 实际专注秒数（暂停要扣掉）
  completed: boolean;      // 是否自然走完（中途放弃 = false）
  task: string;            // 任务名，可空
  interrupt: 'none' | 'internal' | 'external';
  interruptNote?: string;
};
```

- 存储路径：`app.getPath('userData')/data.json`（**不要**放程序目录，否则更新/移动就丢）。
- 写入：先写 `data.json.tmp` 再 `rename`，避免断电写坏。
- 版本字段 `schemaVersion: 1`，以后迁移用。

## 八、风险与预案

| 风险 | 预案 |
|---|---|
| Electron 首装慢/下载失败 | 先 `pnpm create @quick-start/electron`，卡住就换 `electron-vite` 模板；再不行手搓最小 main + Vite renderer |
| 无边框窗口拖动/缩放手感差 | 用 `-webkit-app-region: drag`，按钮区标 `no-drag`；窗口缩放交给系统 `resizable: true` |
| 全局快捷键被占用 | 注册失败要捕获并在设置页提示，允许用户改键（v0.1 可先固定并提示冲突） |
| 提示音在 Windows 上不响 | 不依赖系统提示音，自带 wav 用 `Audio` 播放；打包时确保 wav 进 resources |
| "好看"反复返工 | 第 1 轮先出静态稿拍板，颜色全部走 CSS 变量，改主题只改一个文件 |
| 主进程与界面逻辑混在一起 | 计时状态由主进程持有（关掉窗口计时也要走），渲染层只显示。这条要一开始就定，后面改很痛 |
