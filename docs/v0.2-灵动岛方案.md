# v0.2 灵动岛方案（Windows 顶部悬浮胶囊）

日期：2026-11-22
规划：肥鱼 ｜ 执行：小M
用户原话：「计时的时候是像那个灵动岛一样悬浮在屏幕正上方的中央，和刘海一样的效果，最好就是可以直接在刘海上操作，类似于灵动岛屿，然后风格做好一点」

---

## 一、先说清楚一件事：Windows 没有刘海

macOS/iPhone 有刘海是硬件挖出来的，Windows 顶部是干净的屏幕边缘。所以我们要做的不是"模仿刘海形状"，而是**模仿刘海那种"从屏幕边缘垂下来的常驻小块"的感觉**：

- 窗口贴屏幕最顶端（`y = 0`），**上边两角是直角、下边两角是圆角**，看起来像从屏幕边框里长出来的；
- 常驻、置顶、不进任务栏、不抢焦点；
- 收起时是一小条，鼠标靠近就展开，能直接在条上开始/暂停/跳过。

这个做法在 Windows 上反而比真刘海更协调：因为屏幕边缘本身就是一条直线。

### 本机实测环境（决定了尺寸和位置）

- 主屏 `\\.\DISPLAY1`：1707 × 1067（150% 缩放，物理 2560×1600），**Primary**
- 主屏工作区：`x=48, y=0, 1659 × 1067` —— 说明**任务栏在屏幕左侧（48px 宽）**，顶部和底部都是空的
- 副屏 `\\.\DISPLAY5`：位置 `x=2048, y=621`，1536 × 960

结论：**屏幕顶部中央完全是空的，贴顶不会被任务栏或任何系统 UI 挡住**，这个方案在本机可行。

## 二、形态定义

### 三种状态

| 状态 | 尺寸（DIP） | 内容 | 触发 |
|---|---|---|---|
| **收起**（idle / 运行中） | 172 × 34 | 小圆点 + 剩余时间 | 默认态 |
| **展开**（hover / 点击展开） | 344 × 76 | 任务名 + 剩余时间 + 三个操作 + 进度条 | 指针停留 120ms |
| **提醒**（一段结束） | 344 × 96 | 时间到 + 记录输入（复用现有记录卡片逻辑） | 计时结束 |

窗口外沿再留 14px 给下方阴影，透明区域不铺满，避免大面积挡鼠标。

### 位置

- 默认：主屏顶部正中，`x = (workArea.x + workArea.width - w) / 2`，`y = 0`
- 允许按住 `Alt` 拖动改位置，位置记忆进 `Settings.island = { x, y, pinned }`
- `pinned = true`（默认）时忽略拖动，永远回到顶部正中——**自用场景建议锁死，越简单越不会出错**

### 窗口属性（Electron）

```
frame: false, transparent: true, resizable: false,
alwaysOnTop: true, skipTaskbar: true, hasShadow: false,
focusable: true, show: false（就绪后再显示，避免白闪）
```

- `alwaysOnTop` 用默认层级即可，不要用 `'screen-saver'` 级别（会盖住全屏视频和游戏，很烦）。
- 不设 `focusable: false`：我们需要在胶囊上输入任务名、点按钮。
- 显示时机：`ready-to-show` 之后再 `show()`。

## 三、交互定义（这是需求的核）

| 操作 | 行为 |
|---|---|
| 单击收起态胶囊 | **开始 / 暂停**（最常用的动作给最短路径，不展开） |
| 指针悬停 120ms | 展开 |
| 指针离开 400ms | 收起到展开前的状态 |
| 展开态点「暂停/继续」 | 同单击行为 |
| 展开态点「跳过」 | 跳过当前段，进入下一段 |
| 展开态点时间数字 | 打开主窗口（完整界面：统计、设置） |
| 右键胶囊 | 菜单：打开主界面 / 设置 / 隐藏灵动岛 / 退出 |
| `Esc` | 收起 |
| 展开态可编辑任务名 | 点任务名就地变成输入框，回车保存 |

**关键取舍**：收起态单击 = 开始/暂停，而不是展开。因为用户 90% 的动作是"开始"或"停一下"，展开只是为了改任务名和跳过。这条如果反过来做，每次开始都要先展开再点，等于多一步。

## 四、视觉规范

### 结构（从上往下，贴顶）

```
┌─────────────────────────────┐  ← 屏幕顶部，上边直角
│  ●   24:32                  │  ← 收起态
└─────────────────────────────┘  ← 下边圆角 20px
```

- 下方两角 `border-radius: 0 0 20px 20px`，展开时圆角不变（只变宽高）。
- 背景 `rgba(18,20,24,0.94)`，**不要指望真毛玻璃**：Electron 透明窗口取不到桌面内容做 `backdrop-filter`，糊出来的只是窗内元素。做纯半透明 + 1px 内描边 `rgba(255,255,255,0.08)` 更稳，也不会在静态壁纸下露馅。这条写在这里，省得小M 折腾半天。
- 下方阴影：`0 8px 24px rgba(0,0,0,0.45)`，窗口留的 14px 透明边距就是给它用的。

### 颜色与阶段

沿用现有 `tokens.css`，不引新色相：

| 阶段 | 圆点/进度 | 数字 |
|---|---|---|
| 专注 | `--accent` `#FF6B57` | `--ink` |
| 短休/长休 | `--break` `#5AC49B` | `--ink` |
| 暂停 | 灰 `--ink-2`，整体不透明度 0.75 | `--ink-2` |

### 排版

- 收起态时间：17px / 500，`tabular-nums`
- 展开态时间：34px / 300，`tabular-nums`，字间距 `-0.02em`
- 任务名：13px / `--ink-2`，超长截断加省略号，不换行

### 进度表达

展开态在胶囊**最底部**画一条 2px 的进度条（占满宽度、圆角、`--accent`），比圆环更适合扁平形状。收起态不画条，只靠圆点颜色表达阶段。

### 动效

- 宽高变化：`220ms cubic-bezier(.32,.72,0,1)`（iOS 灵动岛那条曲线），只动 `width` / `height`，别动 `transform: scale`（会糊字）
- 内容切换：新旧内容交叉淡入 120ms，避免文字跳位
- 阶段切换时，整条胶囊做一次极轻的"呼吸"（`opacity` 0.85→1，300ms），作为提醒自己进入下一段的仪式
- 不做频闪、不做弹跳

### 展开态的布局（344 × 76）

左右各 14px 内边距，内容分三列：

```
[ 24:32 ]   写代码           [⏸] [⏭] [↗]
 大字      任务名（可点编辑）   暂停 跳过 主界面
```

底部 2px 进度条压在最下沿。

## 五、技术风险与对策

| 风险 | 为什么难 | 对策 |
|---|---|---|
| **透明区域吃鼠标** | 窗口是矩形，胶囊是圆角，透明处的鼠标事件仍归窗口，会挡住下面网页的点击 | 第一版：窗口紧贴胶囊（只留 14px 阴影余量），能接受；若用户反馈挡手，再上 `setIgnoreMouseEvents(true, {forward:true})` + 渲染层按指针位置切回 |
| 毛玻璃取不到桌面 | Electron 透明窗的 `backdrop-filter` 只糊窗内内容 | 不用真毛玻璃，纯半透明 + 内描边（已写进视觉规范） |
| 全屏应用/游戏被覆盖 | `alwaysOnTop` 会浮在游戏上 | 第一版不做检测，记为已知限制；设置里给"隐藏灵动岛"开关 |
| 多显示器 | 贴顶应该在用户当前用的屏 | 第一版固定主屏，设置里留"跟随鼠标所在屏幕"作为 v0.3 |
| 150% DPI | 尺寸算错会偏移几像素 | Electron 默认用 DIP，坐标用 `screen.getPrimaryDisplay().workArea`，**不要**用 `screen.getAllDisplays()[0].bounds` 硬算物理像素 |
| 两个窗口状态不同步 | 主窗口和胶囊各算各的就会打架 | 都只读主进程状态机，渲染层绝不自己算时间（第 2 轮已定的架构，这里继续守） |
| 睡醒/锁屏后时间不对 | 时间戳算剩余时间的实现天然正确 | 已有，回归测一次即可 |

## 六、分步实现（四个小轮，每轮都能肉眼验收）

| 步骤 | 交付 | 验收 |
|---|---|---|
| **v0.2-a** 骨架 | 透明置顶贴顶窗口，收起态显示剩余时间与阶段色，能跟着主进程状态走 | 屏幕上真的出现一条贴顶胶囊，数字会走，切阶段会变色 |
| **v0.2-b** 交互 | 单击开始/暂停、hover 展开、跳过、点数字开主窗口、右键菜单、Esc 收起、位置锁定 | 手不用离开胶囊就能开关一个番茄 |
| **v0.2-c** 展开态完整 | 任务名就地编辑、进度条、展开/收起动画、两窗口状态同步、设置里加"显示灵动岛"开关 | 展开收起的动画顺滑，不闪不跳 |
| **v0.2-d** 打磨 | 阴影、呼吸动效、阶段切换仪式感、极端尺寸（任务名超长、时长为 1 小时） | 静态截图能当宣传图 |

**每一轮都要出截图**，仍然是用户拍板视觉。

## 七、与 v0.1 的关系

- 主窗口**保留**，作为完整界面（统计、设置、历史）。
- 灵动岛是**常驻浮层**，承担 90% 的日常操作。
- 数据、状态机、存储全部复用，不动 v0.1 已验收的部分。
- 记录卡片继续复用：提醒时在胶囊下方掉出输入区，而不是弹一个居中模态框——这是这次形态改动带来的最大体验提升，因为提醒不再打断你正在看的屏幕中央。
