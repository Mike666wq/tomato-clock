# v0.5 UI 重做：两版方案

日期：2026-11-23
规划：肥鱼
用户原话：「具体的UI也要改，目前这个有点丑」

---

## 一、先说病根

问题不是配色。是**信息结构和视觉层次**：

1. **四行平铺抢注意力**：模板条、主题条、状态行、导航栏，四行权重接近，真正的主角（时间）没有独占感。像设置面板，不像计时器。
2. **圆环太"网页"**：一条纯灰底轨配一根单色弧，没有厚度、没有光，跟灵动岛那种精致感完全不是一个东西。
3. **三个按钮平权**：开始/跳过/重置一样重，每次都要扫一眼找"开始"在哪。
4. **没有呼吸**：所有间距接近，没有主次，眼睛不知道先看哪儿。

所以两版都朝同一个方向改：**让时间成为唯一的视觉焦点，其余元素按重要性退到背景里去。**

---

## 二、A 版 · 极简（推荐）

一句话：**屏幕上只有一圈、一个数字、一个按钮。**

### 布局（480 × 620）

```
┌──────────────────────────────┐
│  专注              ⋯         │  ← 阶段标签左、⋯右，各距边 24
│                              │
│         ╭────────╮           │
│        │          │          │  ← 圆环 Ø = min(w-112, h×0.52)，约 320
│        │  25:00   │          │     环内：时间 96px + 任务名 13px
│        │  准备开始 │          │
│         ╰────────╯           │
│                              │
│     ↺        ▶        ⏭      │  ← 主按钮 Ø72 实心，两侧 Ø40 描边
│                              │
│      今天 2 个 · 50 分钟      │  ← 12px，--ink-3，距底 76
└──────────────────────────────┘
│  ⌂ 计时    ◔ 统计    ⚙ 设置   │  ← 导航高 56，图标 20 + 文字 11
└──────────────────────────────┘
```

- **模板和主题默认不显示**。点右上 `⋯` 从右侧滑出抽屉（宽 280，`--surface` 底），里面：模板列表、主题列表、一行"更多设置"跳转。抽屉外点击关闭。
- 抽屉里选中的项用 `--accent` 左侧 2px 竖条标出。
- 这样主界面永远只有五件东西：阶段标签、圆环、时间、一个按钮组、一行状态。

### 视觉参数

| 元素 | 取值 |
|---|---|
| 圆环直径 | `min(窗口宽 - 112, 窗口高 × 0.52)`，夹在 240–360 之间 |
| 圆环描边 | 8px，圆头 |
| 底轨 | `rgba(237,239,242,0.08)`（深色）/ `rgba(20,22,26,0.10)`（浅色） |
| 进度弧 | 阶段色实色，圆头；结束前 10 秒叠一层 `--warn` |
| 时间字号 | 96px / 字重 200 / `tabular-nums` / 字距 `-0.03em` |
| 阶段标签 | 11px / 500 / 字距 `0.10em` / `--ink-2` / 全大写感 |
| 任务名 | 13px / `--ink-2` / 环内时间下方 8px，超长省略 |
| 主按钮 | Ø72，实心阶段色，内含 28px 播放/暂停图标；悬停 `translateY(-1px)`，按下 `scale(0.96)` |
| 次要按钮 | Ø40，1px `--line` 描边，图标 18px `--ink-2`；悬停底色 `--surface` |
| 按钮间距 | 主按钮两侧各 40 |
| 状态行 | 12px / `--ink-3` / 只有"今天 N 个 · M 分钟"，不写累计（累计去统计页） |

### 动效

- 圆环 `stroke-dashoffset` 持续过渡，`linear`，跟真实时间连续，**不许一秒一跳**
- 点开始那一刻：圆环整体 `scale(1 → 1.015 → 1)`，400ms，仅一次，作为仪式感
- 抽屉滑出 260ms `cubic-bezier(.32,.72,0,1)`
- 阶段切换：数字做 200ms `opacity` 交叉淡出淡入，不要位移

## 三、B 版 · 质感（信息量保留）

一句话：**保留模板和主题，但让它们看起来是"背景"，不是"面板"。**

### 布局（480 × 620）

```
┌──────────────────────────────┐
│         ● 专注  ●            │  ← 阶段胶囊居中：小圆点+文字，底色 --surface
│                              │
│        ╭──────────╮          │  ← 圆环 Ø ≈ 340，12px 渐变描边 + 内发光
│       │            │         │
│       │   25:00    │         │  ← 112px / 200
│       │  写方案     │         │  ← 14px 任务名
│        ╰──────────╯          │
│                              │
│      [   开始   ]  ↺   ⏭     │  ← 主按钮 pill 168×46，两侧 Ø40
│                              │
│  模板  经典 · 深度 · 冲刺     │  ← 26px 高，11px 字，未选中 --ink-3
│  主题  写代码 · 未分类        │  ← 同上，两行之间 8px
│                              │
│  今天 2 个 · 50 分钟 · 累计 320│  ← 12px --ink-3
└──────────────────────────────┘
│  ⌂ 计时    ◔ 统计    ⚙ 设置   │
└──────────────────────────────┘
```

- 两行 chips 保留但**降级**：高度 26、字号 11、未选中 `--ink-3` 无描边、选中才有 `--accent` 描边 + 文字变亮。它们是"标签"不是"按钮"。
- 行首加 `模板`/`主题` 两个 10px 极淡标签（`--ink-3`，字距 0.06em），让这两行有归属。

### 视觉参数（与 A 版不同的部分）

| 元素 | 取值 |
|---|---|
| 圆环描边 | 12px；渐变 `linear-gradient` 从 `--accent` 到 `color-mix(in srgb, var(--accent) 55%, white)` |
| 内发光 | `box-shadow: inset 0 0 60px color-mix(in srgb, var(--accent) 14%, transparent)` |
| 背景光晕 | 环后一层 `radial-gradient(circle, color-mix(accent 7%, transparent), transparent 62%)`，跟随阶段换色 |
| 时间 | 112px / 200 / 字距 `-0.04em` |
| 主按钮 | pill 168 × 46，圆角 23，实心阶段色，文字 15px / 600 |
| 阶段胶囊 | 高 28，圆角 14，`--surface` 底 + 1px `--line`，内含 6px 圆点（阶段色） |

## 四、两版共同的硬规则

1. **颜色只从 `tokens.css` 取**，不新增裸色值；派生色一律 `color-mix`。
2. **不引组件库、不引图标库**：图标用内联 SVG（16/18/20 三个尺寸），路径手写。
3. **深色和浅色两套底都要在图上看清楚**——每版出图时各截一张，共四张。
4. 窗口缩到最小 420×560 时两个版都不能压叠（这条已经踩过一次）。
5. **统计页同步改**：数字卡三列等宽、图表卡片圆角 14、内边距 20、卡片之间 12；标题 12px 字距 0.06em；图表的网格线降到 `--line` 的 60% 不透明度。
6. **灵动岛不动**——它现在的形态是好的，只把它的圆角/颜色跟新版对齐（同一套 token，不改结构）。

---

## 五、怎么交

1. 两版都只做**主界面 + 统计页**的静态稿（不接真数据，用写死的样例数字），各一张深色 + 一张浅色。
2. **不做交互**，不做动画实现，只看静态视觉。
3. 图出来我给用户挑，挑完再改真代码。
4. 挑的时候重点看三件事：**第一眼看到的是不是时间**、**按钮一眼能不能认出开始**、**模板/主题是不是退到背景里去了**。
