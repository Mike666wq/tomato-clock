# v0.5 UI 重做：两版方案

日期：2026-11-23
规划：肥鱼
用户原话：「具体的UI也要改，目前这个有点丑」

---

## 一、先说病根

问题不是配色。是**信息结构和视觉层次**：

1. **四行平铺抢注意力**：模板条、主题条、状态行、导航栏，四行权重接近，真正的主角（时间）没有独占感。像设置面板，不像计时器。
2. **圆环太"网页"**：一条纯灰底轨配一根单色弧，没有厚度、没有光，跟灵动岛那种精致感完全不是一个东西。
3. **三个按钮平权**：开始/跳过/重置一样重，每次都要扫一眼找"开始"在哪。
4. **没有呼吸**：所有间距接近，没有主次，眼睛不知道先看哪儿。

所以两版都朝同一个方向改：**让时间成为唯一的视觉焦点，其余元素按重要性退到背景里去。**

---

## 二、A 版 · 极简（推荐）

一句话：**屏幕上只有一圈、一个数字、一个按钮。**

### 布局（480 × 620）

```
┌──────────────────────────────┐
│  专注              ⋯         │  ← 阶段标签左、⋯右，各距边 24
│                              │
│         ╭────────╮           │
│        │          │          │  ← 圆环 Ø = min(w-112, h×0.52)，约 320
│        │  25:00   │          │     环内：时间 96px + 任务名 13px
│        │  准备开始 │          │
│         ╰────────╯           │
│                              │
│     ↺        ▶        ⏭      │  ← 主按钮 Ø72 实心，两侧 Ø40 描边
│                              │
│      今天 2 个 · 50 分钟      │  ← 12px，--ink-3，距底 76
└──────────────────────────────┘
│  ⌂ 计时    ◔ 统计    ⚙ 设置   │  ← 导航高 56，图标 20 + 文字 11
└──────────────────────────────┘
```

- **模板和主题默认不显示**。点右上 `⋯` 从右侧滑出抽屉（宽 280，`--surface` 底），里面：模板列表、主题列表、一行"更多设置"跳转。抽屉外点击关闭。
- 抽屉里选中的项用 `--accent` 左侧 2px 竖条标出。
- 这样主界面永远只有五件东西：阶段标签、圆环、时间、一个按钮组、一行状态。

### 视觉参数

| 元素 | 取值 |
|---|---|
| 圆环直径 | `min(窗口宽 - 112, 窗口高 × 0.52)`，夹在 240–360 之间 |
| 圆环描边 | 8px，圆头 |
| 底轨 | `rgba(237,239,242,0.08)`（深色）/ `rgba(20,22,26,0.10)`（浅色） |
| 进度弧 | 阶段色实色，圆头；结束前 10 秒叠一层 `--warn` |
| 时间字号 | 96px / 字重 200 / `tabular-nums` / 字距 `-0.03em` |
| 阶段标签 | 11px / 500 / 字距 `0.10em` / `--ink-2` / 全大写感 |
| 任务名 | 13px / `--ink-2` / 环内时间下方 8px，超长省略 |
| 主按钮 | Ø72，实心阶段色，内含 28px 播放/暂停图标；悬停 `translateY(-1px)`，按下 `scale(0.96)` |
| 次要按钮 | Ø40，1px `--line` 描边，图标 18px `--ink-2`；悬停底色 `--surface` |
| 按钮间距 | 主按钮两侧各 40 |
| 状态行 | 12px / `--ink-3` / 只有"今天 N 个 · M 分钟"，不写累计（累计去统计页） |

### 动效

- 圆环 `stroke-dashoffset` 持续过渡，`linear`，跟真实时间连续，**不许一秒一跳**
- 点开始那一刻：圆环整体 `scale(1 → 1.015 → 1)`，400ms，仅一次，作为仪式感
- 抽屉滑出 260ms `cubic-bezier(.32,.72,0,1)`
- 阶段切换：数字做 200ms `opacity` 交叉淡出淡入，不要位移

## 三、B 版 · 质感（信息量保留）

一句话：**保留模板和主题，但让它们看起来是"背景"，不是"面板"。**

### 布局（480 × 620）

```
┌──────────────────────────────┐
│         ● 专注  ●            │  ← 阶段胶囊居中：小圆点+文字，底色 --surface
│                              │
│        ╭──────────╮          │  ← 圆环 Ø ≈ 340，12px 渐变描边 + 内发光
│       │            │         │
│       │   25:00    │         │  ← 112px / 200
│       │  写方案     │         │  ← 14px 任务名
│        ╰──────────╯          │
│                              │
│      [   开始   ]  ↺   ⏭     │  ← 主按钮 pill 168×46，两侧 Ø40
│                              │
│  模板  经典 · 深度 · 冲刺     │  ← 26px 高，11px 字，未选中 --ink-3
│  主题  写代码 · 未分类        │  ← 同上，两行之间 8px
│                              │
│  今天 2 个 · 50 分钟 · 累计 320│  ← 12px --ink-3
└──────────────────────────────┘
│  ⌂ 计时    ◔ 统计    ⚙ 设置   │
└──────────────────────────────┘
```

- 两行 chips 保留但**降级**：高度 26、字号 11、未选中 `--ink-3` 无描边、选中才有 `--accent` 描边 + 文字变亮。它们是"标签"不是"按钮"。
- 行首加 `模板`/`主题` 两个 10px 极淡标签（`--ink-3`，字距 0.06em），让这两行有归属。

### 视觉参数（与 A 版不同的部分）

| 元素 | 取值 |
|---|---|
| 圆环描边 | 12px；渐变 `linear-gradient` 从 `--accent` 到 `color-mix(in srgb, var(--accent) 55%, white)` |
| 内发光 | `box-shadow: inset 0 0 60px color-mix(in srgb, var(--accent) 14%, transparent)` |
| 背景光晕 | 环后一层 `radial-gradient(circle, color-mix(accent 7%, transparent), transparent 62%)`，跟随阶段换色 |
| 时间 | 112px / 200 / 字距 `-0.04em` |
| 主按钮 | pill 168 × 46，圆角 23，实心阶段色，文字 15px / 600 |
| 阶段胶囊 | 高 28，圆角 14，`--surface` 底 + 1px `--line`，内含 6px 圆点（阶段色） |

## 四、两版共同的硬规则

1. **颜色只从 `tokens.css` 取**，不新增裸色值；派生色一律 `color-mix`。
2. **不引组件库、不引图标库**：图标用内联 SVG（16/18/20 三个尺寸），路径手写。
3. **深色和浅色两套底都要在图上看清楚**——每版出图时各截一张，共四张。
4. 窗口缩到最小 420×560 时两个版都不能压叠（这条已经踩过一次）。
5. **统计页同步改**：数字卡三列等宽、图表卡片圆角 14、内边距 20、卡片之间 12；标题 12px 字距 0.06em；图表的网格线降到 `--line` 的 60% 不透明度。
6. **灵动岛不动**——它现在的形态是好的，只把它的圆角/颜色跟新版对齐（同一套 token，不改结构）。

---

## 五、怎么交

1. 两版都只做**主界面 + 统计页**的静态稿（不接真数据，用写死的样例数字），各一张深色 + 一张浅色。
2. **不做交互**，不做动画实现，只看静态视觉。
3. 图出来我给用户挑，挑完再改真代码。
4. 挑的时候重点看三件事：**第一眼看到的是不是时间**、**按钮一眼能不能认出开始**、**模板/主题是不是退到背景里去了**。

## 六、第三轮修正：A/B 两版失败的原因，以及三个真正的风格

**用户反馈：「啥风格啊，我看没啥区别啊」——用户是对的。**

失败原因在我：我把"风格"和"布局"搞混了。A 版和 B 版用的是**同一套视觉语言**（同一个深色底、同一种圆环、同一个字体、同一种按钮），区别只有"模板主题是收进抽屉还是摆在界面上"。那是**排版差异**，不是风格差异。用户要的是"这个东西看起来像另一种东西"，不是"东西摆得不一样"。

所以要出的是**三个视觉语言完全不同**的稿子。判断标准：把三个并排放在一起，一眼能看出是三款不同的产品，而不是同一个产品的三个设置。

---

### 风格一 · 纸感（Paper）

**关键词：安静、纸、墨、没有光。**

| 项 | 取值 |
|---|---|
| 底色 | `#F4F1EA`（暖白，不是纯白） |
| 文字 | `#17170F`（墨黑，不是纯黑） |
| 强调 | `#B8472C`（砖红，压低饱和） |
| 次要文字 | `#8A8578` |
| 圆环 | **2px 极细弧**，没有底轨，只有进度那一段 |
| 数字 | **120px，衬线体**（`"Georgia", "Songti SC", serif`），字距 `-0.01em` |
| 按钮 | 不用圆形实心。用**文字按钮**：`开始` 加一条 1px 下划线，悬停时下划线实起来 |
| 分隔 | 只用 1px `#E2DDD0` 的横线 |
| 禁忌 | 无渐变、无阴影、无发光、无圆角（除了 2px） |
| 感觉 | 像一本摊开的笔记本，或者一个安静的厨房计时器 |

### 风格二 · 玻璃霓虹（Neon Glass）

**关键词：黑、光、脉冲、未来。**

| 项 | 取值 |
|---|---|
| 底色 | `#08090B`，背后一层 `radial-gradient(circle at 50% 30%, #1A0E14, #08090B 70%)` |
| 强调 | `#FF5A3C`，配 12px 外发光 `box-shadow: 0 0 24px rgba(255,90,60,.55)` |
| 圆环 | 10px，进度弧带**双层发光**（内 0 0 8px、外 0 0 24px），底轨 `rgba(255,255,255,0.06)` |
| 数字 | 128px，字重 **100**，字距 `-0.04em`，带极淡 `text-shadow: 0 0 48px rgba(255,90,60,.28)` |
| 面板 | `rgba(255,255,255,0.035)` 底 + 1px `rgba(255,255,255,0.10)` 描边 + 圆角 18 |
| 按钮 | 主按钮圆形 Ø76，实心强调色 + 外发光；次要按钮纯图标，无描边 |
| 动效感 | 呼吸、脉冲、光晕扩散 |
| 感觉 | 像一块贴在屏幕上的发光装置 |

### 风格三 · 系统感（iOS Native）

**关键词：克制、系统、卡片、分段控件。**

| 项 | 取值 |
|---|---|
| 底色 | 深色 `#000000`，卡片 `#1C1C1E`；浅色模式 `#F2F2F7`，卡片 `#FFFFFF` |
| 强调 | `#FF3B30`（系统红） |
| 圆环 | 8px，底轨 `rgba(120,120,128,0.20)` |
| 数字 | 88px，字重 **600**，`tabular-nums`（系统感数字偏粗、偏紧） |
| 字体 | `"Segoe UI Variable", "SF Pro Display", system-ui` |
| 圆角 | 卡片 22，按钮 26（大圆角是 iOS 的骨架） |
| 模板选择 | **分段控件**：一个 `rgba(118,118,128,0.16)` 的胶囊槽，选中项是白色滑块（深色下 `#636366`），带 20ms 过渡 |
| 阴影 | 卡片 `0 4px 24px rgba(0,0,0,0.12)`，不用发光 |
| 感觉 | 像苹果自带的 app，用户不用学 |

---

### 出稿要求（三个都要）

1. 风格一必须是**浅色为主**（它的灵魂是纸），风格二必须**纯深色**，风格三**深浅都出**。
2. 三个稿子的**信息结构可以相同**（时间、阶段、任务名、模板、主题、按钮），**但视觉语言必须不同**——字体、圆角、按钮形态、有没有光、有没有阴影，全都要能区分。
3. 三个稿子**并排截一张对比图**，这张图才是我要拿给用户看的：一眼扫过去必须能说出"这是三个不同的东西"。
4. 每个风格给一句话的自我描述（比如"这是一张纸"／"这是一块发光装置"／"这是苹果自带 app"），用户靠这句话理解我的意图。
5. 仍然遵守：颜色进 tokens、图标手写 SVG、420×560 不压叠。

**如果三个里仍然有两个看起来像同一个东西，那就是没做出来，重做。**

## 七、定案：三个风格都做，做成可切换的主题，默认纸感

用户原话：「一吧，或者说做个主题选项共能。都要」

### 这件事的难点：三套不只是换色

以前 `tokens.css` 只管颜色，加个 `--break` 就是一套新主题。**但这三套的差异在形状和字体上**：

| | 纸感 | 霓虹 | 系统感 |
|---|---|---|---|
| 数字字体 | 衬线 | 超细无衬线 | 系统粗体 |
| 圆角 | 几乎无 | 玻璃胶囊 18 | 大圆角 22–26 |
| 主按钮 | 文字 + 下划线 | 发光圆键 Ø76 | 药丸 168×46 |
| 光 | 无 | 双层发光 | 只有柔和阴影 |
| 底色 | 暖白（只能浅） | 近黑（只能深） | 深浅都行 |

所以需要**两层**：一层是颜色 token（每套一份），一层是**结构变体**（按钮形态、圆角、字体、有没有光）。

### 架构决定

1. **`styles/tokens.css` 只放与主题无关的常量**（间距阶梯、字号阶梯、动效曲线）。
2. **每套风格一个文件**：`styles/themes/paper.css`、`neon.css`、`ios.css`，根选择器 `:root[data-theme="paper"]` 等，里面同时定义：
   - 颜色（`--bg` `--surface` `--ink` `--ink-2` `--ink-3` `--line` `--accent` `--break` `--warn`）
   - 形状（`--radius-card` `--radius-pill` `--radius-btn`）
   - 字体（`--font-num`）
   - 效果（`--shadow-card` `--shadow-btn` `--glow-arc` `--track-alpha`）
3. **允许少量结构覆盖块，但必须集中**：按钮形态这种没法靠变量表达的东西，写在每个主题文件的 `.btn-primary` / `.seg` 等少数几条里，**不许散落到组件**。组件里只准用变量。
4. **默认纸感**：`index.html` 的 `<html data-theme="paper">`，用户在设置里改。
5. **深浅**：纸感只有浅色，霓虹只有深色，系统感支持「跟随系统／浅／深」。切换主题时如果新主题不支持当前深浅，**自动落到它支持的那一档**并在设置里说明。
6. **设置里要有视觉预览**：三张小卡片（各 120×80 的缩略），不是三个下拉选项——用户看不懂"纸感"是什么字。
7. **灵动岛只跟随颜色和圆角，结构不动**。纸感下它就是一条浅纸色胶囊，这是这套风格该有的样子，别怕它显眼。

### 顺手要修的两处

1. **纸感加极淡底轨**（`--track-alpha: 0.02`）。现在 0% 时屏幕上只剩一个数字，环"消失"了，看着像坏了。底轨要淡到几乎看不见，但得在。
2. **进度弧和数字必须一致**。稿子里 25:00 配 70% 的弧，是假数据；真实现里 0% 就是空弧、100% 才满。

### 落地顺序（一轮一件，别一次全上）

1. **主题基建 + 纸感真机**：三份主题文件建好（霓虹和系统感可以先只写颜色、结构后补），主界面切到纸感，真机截图给用户看。用户点头再往下。
2. 统计页跟纸感。
3. 设置页的「外观」分区 + 三张预览卡。
4. 霓虹、系统感的结构补全。
5. 灵动岛跟随。

**第 1 步没得到用户点头，不许做第 2 步。** 纸感是风格最"偏"的一套，用户可能看一眼就觉得不对——那时候后面全白做。
