# 三天自用清单（0.2.0）

> 给你自己的：用真实的一天用下来，比再堆三个功能有用。
> 每天只要记两行：**哪里别扭** + **当时想干什么**。三天后我们按你说的别扭处改。

## 用之前先做两件事（5 分钟）

1. 装 `release\番茄钟 Setup 0.2.0.exe`
2. 建一个主题，比如"写代码"（设置 → 主题 → 新建主题，名字 ≤ 12 字，挑个颜色）
   —— 主题不是待办清单，就是个分类。**不建也能用**，不选就是"未分类"。

---

## 第一天：先别改任何设置，用默认的跑一轮

| 做什么 | 记什么 |
|---|---|
| 启动后，看一眼**屏幕顶端那条胶囊**在不在、有没有挡住你正在看的东西 | 挡视线吗？位置对吗？ |
| 鼠标**移上去**，它展开成两层；把鼠标移开，它收回去 | 展开收起的速度快不快？有没有闪？ |
| **点一下胶囊**（收起态）= 开始/暂停 | 点得准吗？会不会误点到？点完它有没有抢你正在输入的窗口焦点？ |
| 跑完一段（把专注临时改成 1 分钟也行），看**到点提醒** | 吵不吵？弹出来挡不挡屏幕？ |
| 提醒弹出的记录卡片，**回车直接提交** | 3 秒内能不能不打字就完事？ |

**第一天重点问自己**：这条胶囊，我是想天天开着它，还是想关掉它？
（这个问题决定了后面所有打磨的方向。）

---

## 第二天：试模板和主题

| 做什么 | 记什么 |
|---|---|
| 上午用「经典 25/5」，下午换成「冲刺 15/3」（设置里改，或在灵动岛展开后点当前值胶囊） | 切模板顺手吗？切了以后当前这段会不会变？（**应该不变，只影响下一段**） |
| 在灵动岛展开态**点任务名**，写一句"今天写方案"，回车 | 写字方便吗？会不会抢输入法？ |
| 跑完一段，看**统计页 → 主题时间占比** | "写代码"占多少、一共几个番茄、平均多长？ |
| 故意**打断自己一次**（比如中途去干别的），记成"外部打断" | 打断率这个数，对你有用吗？ |

---

## 第三天：用你自己的真实节奏

| 做什么 | 记什么 |
|---|---|
| 按你真实的工作节奏跑一天，模板该换就换、主题该切就切 | 哪些操作你想做但没做成？ |
| 试试**关掉主窗口**（右上角关闭 = 收进托盘），用胶囊计时 | 没有主窗口在眼前，你会不会忘记自己在计时？ |
| 试试把灵动岛**关掉**（托盘右键 → 隐藏灵动岛），再从托盘叫回来 | 找得到吗？ |
| 导出一次 CSV，用 Excel 打开 | 中文乱码吗？字段够用吗？ |

---

## 三天里请重点回答这四个问题

1. **灵动岛**：它是让你更顺手，还是多了一个要看的东西？（这决定它是常驻还是可选）
2. **模板**：你实际用了几套？会不会经常忘切，导致时长不对？
3. **主题**：记任务名这件事，是"顺手"还是"多了一步"？如果多了一步，是名字太难起，还是根本不想起名？
4. **提醒**：到点那一刻，你是被"叫醒"了，还是被"吓了一跳"？

---

## 有问题先看这几处

| 现象 | 去哪看 |
|---|---|
| 胶囊不见了 | 托盘图标右键 → 显示灵动岛；或 设置 → 灵动岛 → 勾上 |
| 记录没保存 | 记录是先落盘再弹卡片的，60 秒自动落一条，所以不会丢 |
| 想备份 | 复制 `%APPDATA%\pomodoro\data.json` 走 |
| 想知道程序在干嘛 | `%APPDATA%\pomodoro\app.log` |
| 想清空重来 | 把 `data.json` 里的 `sessions` 清空，或直接删这个文件（设置会一起重置） |

---

## 反馈怎么给

不用写文档，随手记就行，一行一条：

```
别扭点：<在哪儿、想干什么、结果怎样>
期望：<你本来想它怎样>
```

三天后我们按这些改。**"想砍掉什么"和"哪里别扭"同样重要**——
第一版通常死于东西太多，不是太少。
