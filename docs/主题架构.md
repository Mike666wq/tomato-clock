日期：2026-11-23
执行：小M
方案：`docs/v0.5-UI重做稿.md` 第七节（肥鱼）
状态：**第 1 步已完成**（主题基建 + 纸感真机），第 2–5 步未做

## 一、为什么要两层

以前 `tokens.css` 一个文件管所有颜色，加个 `--break` 就是一套新主题。
但这三套风格的差别**不在颜色，在形状和字体上**：

| | 纸感 | 霓虹 | 系统感 |
|---|---|---|---|
| 数字字体 | 衬线 | 超细无衬线 | 系统粗体 |
| 圆角 | 几乎无（2px） | 玻璃胶囊 18 | 大圆角 22–26 |
| 主按钮 | 文字 + 1px 下划线 | 发光圆键 Ø76 | 药丸 |
| 光 | 无 | 双层发光 | 只有柔和阴影 |
| 底色 | 暖白（只能浅） | 近黑（只能深） | 深浅都行 |

换颜色换不出"文字按钮"和"发光圆键"的差别。所以分成两层：

1. **`styles/tokens.css`：与主题无关的常量**——间距、字号、动效曲线、阶段色映射。
   组件里能用它，但它不含任何一套主题特有的值。
2. **`styles/themes/{paper,neon,ios}.css`：一套一个文件**，根选择器
   `:root[data-theme="paper"]`，里面同时定义：
   - 颜色：`--bg` `--surface` `--ink` `--ink-2` `--ink-3` `--line` `--accent` `--break` `--warn` `--on-phase` `--track` `--hover` `--active`
   - 形状：`--r-sm` `--r-md` `--r-lg` `--r-pill` `--ring-stroke`
   - 字体：`--font-num`
   - 效果：`--shadow-card` `--shadow-btn` `--shadow-focus` `--glow-arc` `--app-bg`

## 二、结构覆盖块：只准待在主题文件里

按钮形态这种事没法用变量表达。三套的按钮差别这么大，
所以每个主题文件里允许有**少量结构覆盖块**（`.btn--primary`、`.presets__chip` 等），
但必须**集中在主题文件里，不许散进组件**。

组件里只准用变量。这条是防止三套风格长进代码里——以后改一处要找三个文件。

选择器一律写成 `:root[data-theme='paper'] .btn--primary`，
靠 `:root[data-theme]` 提高优先级，压得住 `app.css` 里的默认形态。

## 三、深浅

- 纸感**只有浅色**、霓虹**只有深色**、系统感支持「跟随系统／浅／深」。
- 切主题时如果新主题不支持当前深浅，**自动落到它支持的那一档**
  （`resolveUiTheme()`，在 `src/shared/types.ts`），不让用户切完发现没反应。
- 深浅写在 html 的 `data-mode` 上；系统感用它区分两套配色：
  `:root[data-theme='ios'][data-mode='light']`。
- 跟随系统时，系统深浅变了界面要跟着变（`useTheme()` 里监听
  `prefers-color-scheme`）。

## 四、窗口底色

窗口底色必须和界面底色一样，否则**纸感（浅底）启动时会先闪一下黑**。
`src/main/index.ts` 的 `windowBgOf()` 按主题算出底色，
建窗口时和换主题时各设一次。

`UI_THEME_BG` 在 `src/shared/types.ts` 里，跟界面 token 一一对应。

## 五、灵动岛：暂时独立

灵动岛是独立的第二个窗口，有自己的形态和配色（深色玻璃胶囊），
跟主窗口的主题无关。它的皮肤单独放在 `styles/themes/island-glass.css`，
由 `island.tsx` 单独引入（主窗口不加载它）。

**v0.5 第 5 步**才让灵动岛跟随主窗口主题——那时候这个文件会并进主题层。

## 六、环的描边宽度跟主题走

描边宽度不只是颜色：纸感 2px 细弧、霓虹 10px、系统感 8px。
而环的半径要让开描边（`radius = (直径 - 描边) / 2 - 4`），
所以宽度一变，半径和时间字号都得跟着重算。

`src/renderer/useTheme.ts` 的 `useThemeNumber()` 读主题里的
`--ring-stroke`，并监听 `data-theme` / `data-mode` 的变化。

环的**尺寸规则**也是主题的一部分，三个变量：

| 变量 | 意思 | 默认 |
|---|---|---|
| `--ring-max` | 环的最大直径 | 420 |
| `--ring-mx` | 环离左右至少留多少 | 56 |
| `--ring-gap` | 环离上下至少留多少 | 10 |

`Timer.tsx` 里的算法：`直径 = min(最大, 可用宽 - 左右留白, 可用高 - 2×上下留白)`。
原来写的是 `可用高 × 0.94`——那是个比例，环区一变高，留白就跟着变，
"环离按钮多远"根本不可控。换成固定留白才量得准。

## 七、纸感的结构覆盖（这一轮做的）

都集中在 `styles/themes/paper.css`：

- **标题栏**：去掉"番茄钟"三个字（信息重复），高度压到 32px（`--titlebar-h`），
  底部导航那条 1px 分隔线也去掉——让它和内容连成一片纸。
- **阶段标签**：靠左（`align-self: flex-start`），和下面模板/主题两行对齐成一条竖线。
- **模板/主题两行**：左右加 24px 内边距（原来顶在窗口边界上，"模"字被切——
  **这是 bug，三套主题都受影响，所以修在 app.css 里**）。
- **前缀标签**「模板」「主题」：纸感里去掉，内容本身就能看出是两行不同的东西。
- **主题行的小圆点**：去掉，只在选中项留一个——纸感的语言是"线"不是"点"。
- **垂直节奏**：环按 `--ring-gap` 贴住这一格，下面那组（按钮 + 模板 + 主题 + 状态）
  自己收紧，整体更靠近底部，环更居中。

**数字字体用 Cambria 而不是 Georgia**：Georgia 的数字默认是**旧式数字**
（2 和 5 是 x 字高、0 是全高），秒数一变整个数字上下跳，跟"跳秒不抖"冲突。
Cambria 默认就是等高数字。数字的字重也跟着主题走（`--font-num-weight`）。

## 八、怎么加一套新主题

1. 新建 `styles/themes/xxx.css`，照着 `paper.css` 抄结构：
   颜色、形状、字体、效果、结构覆盖块。
2. `src/shared/types.ts`：`UiTheme` 加一项，`UI_THEMES` 加一条元信息，
   `UI_THEME_BG` 加一组底色。
3. `src/renderer/main.tsx` 里 `import './styles/themes/xxx.css'`。
4. `resolveUiTheme()` 里如果这套只支持一种深浅，在 `UI_THEMES` 的 `modes` 写上。

## 十、踩过的坑

1. **CSS 变量写在规则外面是无效声明**。我重写 `tokens.css` 时把常量写在
   `:root {}` 外面，浏览器直接忽略——`getPropertyValue('--titlebar-h')`
   读出来是空串，标题栏高度退回内容高度（23px），看着像"没写样式"。
   **变量必须在 `:root` 里。**
2. **旧式数字（old-style figures）会让秒数上下跳**。Georgia 的 2/5 是 x 字高、
   0 是全高，衬线好看但不能用来显示计时。数字字体要选默认等高的（Cambria）。
3. **环的"离上下多远"要用固定留白，不要用比例**。`高 × 0.94` 这种比例在
   窗口高度变化时留白跟着变，"环和按钮之间应该隔多少"就没法定下来了。
4. **GDI 抓桌面会误伤**：按窗口类名枚举去最小化"别的窗口"，会连同 Electron
   窗口一起收掉（用户的 DS Bot 也被收起来过一次）。所以壁纸对照用合成，不动桌面。
