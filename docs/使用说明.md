# 番茄钟 使用说明

> 自用版本 0.1.0 ｜ 日期：2026-11-22 ｜ Windows x64
> 这是一个只给自己用的桌面番茄钟：零账号、纯本地、不联网、不自动续费。

---

## 一、装 / 卸载

| 包 | 路径 | 说明 |
|---|---|---|
| 安装包 | `release\番茄钟 Setup 0.1.0.exe` | NSIS 安装包，双击装，可选安装目录 |
| 免安装 zip | `release\番茄钟-0.1.0-免安装.zip` | 解压即用，不写注册表 |
| 免安装单文件 | `release\番茄钟 0.1.0.exe` | 一个 exe，双击即用 |

安装后：
- 程序在 `%LOCALAPPDATA%\Programs\pomodoro\`
- 桌面会建快捷方式
- 卸载走"设置 → 应用 → 卸载"或 `Uninstall 番茄钟.exe`

> **卸载不会删数据。** 记录和设置都在 `%APPDATA%\pomodoro\`，
> 装一次、卸一次、重装一次，记录都还在（已实测）。

---

## 二、怎么用

1. 启动后窗口会显示 25:00，按 **开始**（或按空格）。
2. 一段跑完会：窗口自动弹到最前面 + 响一声 + 弹系统通知 + 边框闪三下。
3. 提醒后弹一张记录卡片：
   - 上面一格写"刚才在做什么"（可以留空）
   - 下面三个选打断类型：没被打断 / 内部打断 / 外部打断
   - **回车直接保存**，3 秒内不用碰鼠标
   - 60 秒没人理，会自动按"已完成、无任务、无打断"记一条
4. 底部一行是今天的数据：今日几个番茄、今日专注多少分钟、累计多少分钟。
5. 底部三个页签：**计时 / 统计 / 设置**。

### 窗口行为

- 右上角：最小化、关闭（**关闭 = 收进托盘，不退出**，计时照样走）
- 拖标题栏可以挪窗口，位置和大小会记住
- 托盘图标跟着阶段变：专注是红番茄、休息是绿番茄、暂停是灰番茄
- 左键点托盘图标 = 拉出窗口；右键 = 菜单（开始/暂停、显示窗口、退出）

## 三、快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + Space` | 开始 / 暂停 |
| `Ctrl + Alt + P` | 显示窗口 |

可以在 **设置 → 全局快捷键** 里改。改完如果那个组合键被别的程序占了，
界面上会弹提示，**原来的键仍然可用**（不会把功能弄丢）。

窗口内快捷键：**空格** = 开始/暂停，**回车** = 保存记录，**Esc** = 跳过记录。

## 四、数据在哪 / 怎么备份

| 内容 | 位置 |
|---|---|
| 全部记录 + 设置 | `%APPDATA%\pomodoro\data.json` |
| 运行日志 | `%APPDATA%\pomodoro\app.log` |
| 提示音、图标 | 程序目录下的 `resources\resources\` |

**备份**就是把 `data.json` 复制走（或者复制整个 `%APPDATA%\pomodoro` 文件夹）。
恢复的时候把文件放回去即可。

**彻底卸载干净**（连数据一起删）：

```powershell
Remove-Item -Recurse -Force "$env:APPDATA\pomodoro"
```

## 五、导出 CSV

设置页 → 数据 → **导出 CSV**。

- 选个保存位置，文件叫 `番茄钟记录-YYYYMMDD.csv`
- **带 UTF-8 BOM**，Excel 直接双击打开不会乱码
- 字段：日期、阶段、开始、结束、计划秒、实际秒、暂停秒、是否完成、任务、打断类型
- "实际秒"是真正在跑的时间，暂停的时间单独记在"暂停秒"

---

## 六、统计页怎么看

- **今日按小时分布**：看自己什么时段最容易进入状态
- **近 7 天趋势**：看有没有断档（空的日子什么都不画）
- **打断原因排行**：内部打断多，说明是自己在摸鱼；外部打断多，说明环境在打断你

第一次用还没有记录时，统计页会显示"今天还没开始"，不是空白框。

## 七、设置页

| 项 | 说明 |
|---|---|
| 专注 / 短休 / 长休 时长 | 分钟数 |
| 几个番茄后长休 | 默认 4 轮 |
| 结束提示音 | 开关 + 音量 |
| 自动开始下一段 | 默认关（自己决定什么时候开始下一段） |
| 开机自启 | 装完可以开 |
| 全局快捷键 | 改键 |
| 导出 CSV | 见上一节 |

**一条规则**：计时进行中改时长，**只影响下一段**，当前这一段不变，界面上也会提示。
不是程序坏了，是故意的——不打断正在跑的这一段。

## 八、常见问题

**Q：到点了没反应？**
A：先看是不是被"专注助手"吞了通知——但本程序的强提醒是"窗口置顶 + 声音 + 系统通知"三件一起，
不依赖系统提示音。另外确认托盘里图标还在（进程活着）。

**Q：记录没保存？**
A：记录是先落盘再弹卡片的，60 秒自动落一条。所以即使没填任何东西，那一段也已经在库里了。

**Q：想清空记录？**
A：把 `%APPDATA%\pomodoro\data.json` 里的 `sessions` 数组清空，或者直接删掉这个文件（会重置设置）。

**Q：占位符图标 / 提示音不对？**
A：资源文件在 `resources\resources\`，重新生成用
`pwsh -File scripts\gen-assets.ps1`。
