# 番茄钟 使用说明

> 自用版本 0.3.1 ｜ 日期：2026-11-23 ｜ Windows x64
> 这是一个只给自己用的桌面番茄钟：零账号、纯本地、不联网、不自动续费。

> **卸载不会删数据。** 记录和设置都在 `%APPDATA%\pomodoro\`，
> 装一次、卸一次、重装一次，记录都还在（已实测：卸载后目录、快捷方式、注册表项全清，
> `data.json` 与其中的主题完好）。

## 二、灵动岛（屏幕顶端那条胶囊）

**这是日常最常用的地方**，主窗口是完整界面，灵动岛是常驻在屏幕顶端中央的悬浮条。

### 收起态（172×34）

- 一个圆点 + 剩余时间，圆点颜色跟阶段走：**专注红 / 休息绿 / 暂停灰**
- **点一下 = 开始 / 暂停**（不是展开，别多点一下）
- 鼠标移上去会展开成两层

### 展开第一层（344×92，开音乐控制时 344×118）

```
25:00   点这里写这一段做什么        ▶  ⏭  ↗
        [经典 · 25/5]  [未分类]
```

- **点任务名** → 变成输入框，写完回车，这一段的记录里就带着这个名字
- **▶ / ⏭ / ↗** 分别是 开始暂停 / 跳过本段 / 打开主界面
- 下面两个胶囊是**当前值**：左边是计时模板，右边是主题
- **点胶囊展开第二层**，第二层换成那一项的候选（一次只开一行，不叠加）
- **Esc** 先收回第二层，再收起整个岛
- 最下面那一行是**音乐控制**（默认关，见第五节之二）；收起态不显示这一行

### 灵动岛不见了怎么办

1. **托盘图标右键 → 显示灵动岛**（最快）
2. 或者 **设置 → 灵动岛 → 勾上"在屏幕顶端显示灵动岛"**
3. 或者直接**右键胶囊 → 隐藏灵动岛**（会记下来，下次启动仍然隐藏）

> 这个开关和托盘菜单是同一条路：都改 `%APPDATA%\pomodoro\data.json` 里的 `islandVisible`。

### 灵动岛的其它行为

- 永远贴在**屏幕顶端正中**，位置不随窗口移动
- 常驻置顶，不抢焦点；主窗口关掉（收进托盘）它照常在
- 右键胶囊：打开主界面 / 设置 / 隐藏灵动岛 / 退出

## 三、主窗口怎么用

1. 启动后窗口会显示 25:00，按 **开始**（或按空格）。
2. 一段跑完会：窗口自动弹到最前面 + 响一声 + 弹系统通知 + 边框闪三下。
3. 提醒后弹一张记录卡片：
   - 上面一格写"刚才在做什么"（可以留空；如果在灵动岛写过，这里已经有了）
   - 下面三个选打断类型：没被打断 / 内部打断 / 外部打断
   - **回车直接保存**，3 秒内不用碰鼠标
   - 60 秒没人理，会自动按"已完成、无任务、无打断"记一条
4. 底部一行是今天的数据：今日几个番茄、今日专注多少分钟、累计多少分钟。
5. 底部三个页签：**计时 / 统计 / 设置**。

### 窗口行为

- 右上角：最小化、关闭（**关闭 = 收进托盘，不退出**，计时照样走）
- 拖标题栏可以挪窗口，位置和大小会记住
- 托盘图标跟着阶段变：专注是红番茄、休息是绿番茄、暂停是灰番茄
- 左键点托盘图标 = 拉出窗口；右键 = 菜单（开始/暂停、显示窗口、显示/隐藏灵动岛、退出）

## 四、计时模板

**模板 = 能来回切的几套时长。** 上午写代码用「深度 50/10」，下午处理零碎事用「冲刺 15/3」，切一下就换，不用重调数字。

- **内置四个**：经典 25/5、深度 50/10、冲刺 15/3、考试 45/10。**内置的不能删，但可以复制成自己的再改。**
- **自定义**：设置 → 计时模板 → 新建模板。名称 ≤ 12 字，专注 1–180 分钟，短休 1–60，长休 1–90，轮数 1–12。
  **超范围会直接拒绝并说明原因**（比如"专注要在 1–180 之间，你填的是 200"），不会偷偷改成别的值。
- **切模板**：主界面计时页有一排模板胶囊；灵动岛展开后点当前值胶囊也能切。
  模板多了一行放不下时，**那一行可以横向滚动**（右边会渐隐，提示还有），不会把下面的东西挤掉。
- **规则**：计时进行中切模板**只影响下一段**，当前这一段不变；这一段还没开始跑的话，切了立刻生效。

## 五、主题（项目 / 分类）

**主题不是待办清单**，没有完成状态、没有优先级、没有截止时间。它就是个长期归类空间——
"写代码""写报告""学英语"，番茄挂上去，时间就归上去。

- **设置 → 主题 → 新建主题**：起个名，从固定调色板里挑个颜色
- **允许不选**：选择器第一个是「未分类」，不选也能计时（强制选会让人为了开始计时先建一个主题）
- **改名 / 归档**：归档后不再出现在选择器里，但**历史记录保留**
- **灵动岛展开后**点右边的当前值胶囊就能切主题
- **休息段不挂主题**，只有专注段挂

### 主题能看出什么（统计页）

- **主题时间占比**：横条排行，本周 / 全部两个口径
- 每个主题下面有：**回合数、总时长、平均每回合时长、打断率**
- **打断率** = 这个主题的完成回合里被打断的比例。这是主流产品都不给的一个数，
  它回答的是"这块活为什么总也干不完"，而不是"你今天坐了多久"
- **今日概览**：今天涉及几个主题、几个番茄，按主题分组

## 五之二、音乐控制（灵动岛里控制 QQ 音乐）

**设置 → 灵动岛 → 勾上"在灵动岛里显示音乐控制"**，打开之后：

- 灵动岛**展开态最下面**多一行：`♪ 歌名 - 歌手` + 三个按钮（上一首 / 播放暂停 / 下一首）
- **收起态不显示**这一行（收起态只有 172 宽，塞不下）
- 歌名太长会**截断加省略号**，不会把胶囊撑破
- **没开音乐软件时这一行整个消失**，不留空位、不报错——没开音乐是常态，不是故障
- 音乐软件关了、或者它自己挂了，这一行同样直接消失，程序照常用

它认的是 Windows 的 **SMTC**（系统媒体传输控制），所以不只 QQ 音乐：
Edge / Chrome 播网页音乐、Spotify、系统自带媒体播放器，一般都能读到歌名。

> **想关就关**：设置里取消勾选即刻生效（不用重启），托盘里也能直接把整个灵动岛藏起来。
>
> **它是怎么做到的**：主进程拉一个很小的辅助程序（`resources\resources\smtc\smtc.exe`，24MB，
> 随安装包一起装），它每秒报一次"现在在放什么"，按钮的命令也发给它。
> 这个辅助程序需要 **.NET 8 运行时**（本机已装；没装的话只是音乐那一行不出现，别的照常用）。

## 六、快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + Space` | 开始 / 暂停 |
| `Ctrl + Alt + P` | 显示窗口 |

可以在 **设置 → 全局快捷键** 里改。改完如果那个组合键被别的程序占了，
界面上会弹提示，**原来的键仍然可用**（不会把功能弄丢）。

窗口内快捷键：**空格** = 开始/暂停，**回车** = 保存记录，**Esc** = 跳过记录。

## 七、数据在哪 / 怎么备份

| 内容 | 位置 |
|---|---|
| 全部记录 + 设置 | `%APPDATA%\pomodoro\data.json` |
| 运行日志 | `%APPDATA%\pomodoro\app.log` |
| 提示音、图标 | 程序目录下的 `resources\resources\` |

**备份**就是把 `data.json` 复制走（或者复制整个 `%APPDATA%\pomodoro` 文件夹）。
恢复的时候把文件放回去即可。

**彻底卸载干净**（连数据一起删）：

```powershell
Remove-Item -Recurse -Force "$env:APPDATA\pomodoro"
```

## 八、导出 CSV

设置页 → 数据 → **导出 CSV**。

- 选个保存位置，文件叫 `番茄钟记录-YYYYMMDD.csv`
- **带 UTF-8 BOM**，Excel 直接双击打开不会乱码
- 字段：日期、阶段、开始、结束、计划秒、实际秒、暂停秒、是否完成、任务、打断类型
- "实际秒"是真正在跑的时间，暂停的时间单独记在"暂停秒"

---

## 九、统计页怎么看

- **今日按小时分布**：看自己什么时段最容易进入状态
- **近 7 天趋势**：看有没有断档（空的日子什么都不画）
- **打断原因排行**：内部打断多，说明是自己在摸鱼；外部打断多，说明环境在打断你
- **主题时间占比**：看时间到底花在哪些事上，以及哪块活最容易被打断

第一次用还没有记录时，统计页会显示"今天还没开始"，不是空白框。

## 十一、常见问题

**Q：到点了没反应？**
A：先看是不是被"专注助手"吞了通知——但本程序的强提醒是"窗口置顶 + 声音 + 系统通知"三件一起，
不依赖系统提示音。另外确认托盘里图标还在（进程活着）。

**Q：记录没保存？**
A：记录是先落盘再弹卡片的，60 秒自动落一条。所以即使没填任何东西，那一段也已经在库里了。

**Q：灵动岛怎么不见了？**
A：托盘图标右键 → 显示灵动岛；或设置 → 灵动岛 → 勾上开关。

**Q：想清空记录？**
A：把 `%APPDATA%\pomodoro\data.json` 里的 `sessions` 数组清空，或者直接删掉这个文件（会重置设置）。

**Q：占位符图标 / 提示音不对？**
A：资源文件在 `resources\resources\`，重新生成用
`pwsh -File scripts\gen-assets.ps1`。
