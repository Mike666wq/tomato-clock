# 0.3.6

日期：2026-11-24

## 这次解决什么

**① 灵动岛上能调系统总音量了**

点岛上的喇叭图标，歌名区会变成一条滑条，拖它就改系统音量 ——
跟键盘上的音量键是**同一个数**，所有应用的声音一起变大变小。

- 拖动跟手，松开就落在最终值；
- 外部按音量键，滑条位置跟着动；
- 拖完 3 秒不动自动收起；滚轮也能调（±5%）。

**② 音乐控制的按钮永远在**

以前"现在在放什么歌"读不到的时候，整行按钮会跟着消失 ——
于是变成"看着有按钮、点了一点反应都没有"。

现在：

- **按钮永远在**（上一首 / 播放暂停 / 下一首 / 音量）；
- **歌名能读到才显示，读不到就不显示**（不显示假的）；
- 控制走的是**真媒体键**（跟键盘上的播放键同一套），不依赖那个时好时坏的口子。

**③ 读不到歌名不是坏了**

Windows 上读"现在在放什么歌"只有一个官方接口，它在这台机器上**时好时坏**
（昨晚还能读到歌名，之后就读不到了）。
读不到的时候你看到的是：**按钮都在、点得动，只是没有歌名**。
那不是坏了，是那个接口暂时不可用。

## 其它

- 媒体子进程加了**自愈**：解锁屏幕或从睡眠恢复后会自动重启它；
  读不到会话时会丢掉缓存重试，再不行就换一个进程。
- 修了几处"看起来点了其实没动"的问题：命令发出去但界面骗你的那几种。

## 已知限制

- **媒体键是全局的**：同时有别的播放器在放时，这一下可能打到别人身上。
  这是 Windows 的机制，不是这个应用的 bug。
- 读不到歌名时，播放/暂停按钮显示的是**两态图标**（点一下切换），
  而不是"当前在放/在停"——因为那时候确实不知道是哪种状态。

## 升级

下载安装包覆盖安装即可，**你的数据不会丢**。
