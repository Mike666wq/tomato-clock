# 验证方法

> 这台机器上窗口**拿不到前台**，模拟鼠标点击、键盘输入会落到桌面上，对应用无效。
> 所以本项目的自动化验证统一走 **DevTools 协议（CDP）**：直接驱动渲染层，
> 读真实状态、写真实 DOM，不用猜。
>
> 记录人：小M ｜ 最后更新：2026-11-22（第 3 轮）

## 二、CDP 验证：`scripts/cdp-check.mjs`

用法：

```powershell
node scripts\cdp-check.mjs "表达式1" "表达式2" ...
```

- 每个表达式都在**渲染页面的上下文**里求值（`Runtime.evaluate`，`awaitPromise: true`）
- 输出格式：`表达式` 换行 `=> 结果`；抛错会打印 `!! 错误信息`
- 返回值用 `JSON.stringify` 呈现，对象/数组能直接看

### 常用断言模板

```powershell
# 1) 通道是否通（preload 有没有挂上）
node scripts\cdp-check.mjs "typeof window.pomodoro"

# 2) 主进程当前的计时状态
node scripts\cdp-check.mjs "window.pomodoro.timer.getState()"

# 3) 界面当前显示的东西（比截图更精确）
node scripts\cdp-check.mjs "document.querySelector('.ring__time')?.textContent" "document.querySelector('.phase-label')?.textContent"

# 4) 发动作（等价于用户点按钮）
node scripts\cdp-check.mjs "window.pomodoro.timer.action('toggle')"

# 5) 等一会儿再读（观察倒计时）
node scripts\cdp-check.mjs "new Promise(r=>setTimeout(()=>r(window.pomodoro.timer.getState()),3000))"

# 6) 写 DOM（模拟用户在输入框里打字，React 受控组件必须走原生 setter）
node scripts\cdp-check.mjs "(()=>{const el=document.querySelector('.record-card__input');const s=Object.getOwnPropertyDescriptor(window.HTMLInputElement.prototype,'value').set;s.call(el,'写方案');el.dispatchEvent(new Event('input',{bubbles:true}));return 'FILLED'})()"

# 7) 触发回车提交
node scripts\cdp-check.mjs "document.querySelector('.record-card').dispatchEvent(new KeyboardEvent('keydown',{key:'Enter',bubbles:true}))"

# 8) 点某个按钮（按 class 选）
node scripts\cdp-check.mjs "document.querySelectorAll('.chip')[2].click()"
```

### 只在开发模式存在的两个后门

用来把长流程压缩成几秒，**打包产物里完全没有**（第 3 轮 grep 验证过）：

| 后门 | 作用 |
|---|---|
| `window.pomodoro.timer.devSeed(phase, elapsedSec)` | 把计时器摆到指定阶段与"已过秒数"，`elapsedSec` 大于 0 时会真的跑起来，用来快速触发阶段流转 |
| 环境变量 `POMODORO_PHASE` / `POMODORO_ELAPSED` | 启动时直接摆到指定状态，用来截指定状态的图 |

例：

```powershell
# 3 秒内走完一个专注段（1499 = 25:00 差 1 秒）
node scripts\cdp-check.mjs "window.pomodoro.timer.devSeed('focus',1499)" "new Promise(r=>setTimeout(()=>r(window.pomodoro.timer.getState()),2500))"
```

## 五、每轮要验的清单

按顺序过，缺一条不算完成：

1. **通道**：`typeof window.pomodoro` → `"object"`
2. **计时在走**：`getState()` 的 `remainingSec` 随时间递减
3. **窗口关了也在走**：关闭窗口（`taskkill /PID <pid>`，不要用 `/F`）→ 等 20 秒 → `getState()` 的 `remainingSec` 掉了约 20
4. **阶段流转**：连续 seed 4 次专注 → `focusRounds` 到 4 时阶段变 `long`
5. **落盘**：阶段结束后 `data.json` 多一条 `sessions`
6. **actualSec 口径**：`plannedSec`/`actualSec`/`pausedSec` 与墙钟跨度对得上（`actualSec + pausedSec ≈ 墙钟跨度`）
7. **重启恢复**：重启应用 → 底部状态行的"今日 N 个番茄"恢复
8. **打包产物干净**：`pnpm build` 后 grep 下面这些关键字，必须 **0 命中**：
   `POMODORO_SHOT`、`capturePage`、`devSeed`、`POMODORO_PHASE`、`POMODORO_ELAPSED`、`remote-debugging-port`、`timer:dev-seed`、`9222`

```powershell
pnpm build
foreach ($k in @('POMODORO_SHOT','capturePage','devSeed','POMODORO_PHASE','POMODORO_ELAPSED','remote-debugging-port','timer:dev-seed','9222')) {
  $n = (Select-String -Path out\main\index.js,out\preload\index.js,out\renderer\assets\*.js -SimpleMatch -Pattern $k | Measure-Object).Count
  "{0,-24} {1}" -f $k, $(if ($n -eq 0) { '未出现 ✅' } else { "出现 $n 次 ❌" })
}
```

## 六、踩过的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| `Cannot read properties of undefined (reading 'requestSingleInstanceLock')` | 环境里预置了 `ELECTRON_RUN_AS_NODE=1`，Electron 退化成纯 Node | `scripts/dev.mjs` 已自动清理 |
| 截图只拍到桌面壁纸 | 窗口没在前台，`CopyFromScreen` 截到的是桌面 | 用 Electron 的 `capturePage()`，或 CDP |
| 截图内容被放大 1.5 倍并裁掉 | `PrintWindow` 按 DPI 放大输出，而位图按逻辑尺寸建 | 同上，别用 `PrintWindow` |
| 模拟点击没反应 | 点击落到桌面上了 | 改用 CDP 直接驱动渲染层 |
| `No handler registered for 'timer:dev-seed'` | 改主进程时把 DEV 块里的 handler 删掉了 | 注意 DEV 块与正式逻辑的对应关系 |
| 提示条不显示 | 主进程在渲染层挂载前推送，订阅还没建立，消息丢了 | 改成拉取式：渲染层挂载后 `notice.take()` |
| `pnpm add` 时 TypeScript 7 的原生二进制反复超时 | TS 7 是原生实现 | 钉 `typescript@^5.9` |
