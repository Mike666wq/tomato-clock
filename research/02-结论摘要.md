# 市场调研结论摘要（给小M这一轮，供肥鱼汇总）

> 完整数据见：`01-国内与新兴番茄钟产品调研.md`

## 一句话结论

**值得做，但只能做成「Windows 桌面端 + 零账号纯本地 + 任务维度复盘 + 桌面级干扰阻断」的个人生产力工具；做成「游戏化番茄钟 App」或「又一个通用番茄钟」不值得。**

## 五个支撑事实

1. **功能已经做完了**：番茄+白噪音+热力图+小组件+待办+Health 同步+Watch 端，全都有，用户不缺功能。
2. **移动端已饱和**：番茄ToDo 94.3 万评价、小日常 55.3 万、Forest 中国区 25.9 万；头部均分全部 ≥4.78，评分无法再拉开差距。
3. **PC 桌面端是真空**：番茄ToDo / Forest / 椅子上有猫 都没有原生 Windows 客户端；潮汐用户公开求 PC 版；Pomofocus 虽有客户端，但只是免费版（带广告）的裸打包。
4. **订阅信任是品类级雷区**：潮汐 1 星评论几乎全部在骂"试用默认勾选年费→直接扣 198"、"强制绑免密支付"、"扣费无提示"、"客服不回复"。滴答也有"续费无通知直接扣 168"。
5. **统计都没回答"时间去哪了"**：主流统计只有总时长+热力图+番茄数；滴答用户投诉桌面专注时长与实际不符（8h14m 显示 7h 多）。

## 五个可攻的痛点（P0→P2）

| 级别 | 痛点 | 已有产品现状 |
|---|---|---|
| P0 | 订阅信任危机 | 试用诱导扣费、退款难、客服失灵 |
| P0 | 桌面端缺位 + 强制力天花板 | iOS 能"拦截其他 App 打开"是 OS 级能力；桌面端没人做 |
| P1 | 跨端不一致 | 手机/电脑两套记录；潮汐 Mac 版不完整 |
| P1 | 统计维度太浅 | 只有总时长，无任务/项目维度 |
| P1 | 复杂化正在杀死老用户 | Forest、小日常、滴答被同一条评论骂"变繁琐" |
| P2 | 专注产品自己变干扰源 | 潮汐营销推送、小日常开屏广告 |
| P2 | 数据不可控 | 小日常"不开 iCloud 历史数据全清空" |

## 立项红线（出现任意一条就别做）

- 做游戏化番茄钟（种树/养猫）→ 赛道已占死
- 做移动端 App 冲榜 → 商店位置和心智已占死
- 做纯网页版 → Pomofocus 免费版功能已够用（带广告，Premium $18/年去广告）还带桌面端，替代品充足
- 靠订阅变现且无差异化 → 没有品牌背书时踩订阅信任坑必翻车
- 指望"统计做得漂亮"取胜 → 统计长得都一个样
