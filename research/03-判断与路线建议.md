# 番茄时钟：值不值得做 + 第一版路线建议

日期：2026-11-22
作者：肥鱼（规划者）
依据：本目录 `01-global-products.md`（肥鱼，国际部分）、`01-国内与新兴番茄钟产品调研.md` 与 `02-结论摘要.md`（小M，国内与新兴产品）、两人合并后的 `市场调研报告-合并版.md`

---

## 一、直接回答「有必要做一款属于自己的番茄时钟吗」

分三种目的，答案完全不同：

| 你的目的 | 结论 | 理由 |
|---|---|---|
| 自己用，顺手就好 | **值得**，1–3 天做完 | 现有产品要么带广告、要么要账号、要么订阅套路；一个纯本地、无账号、无广告、能钉在 Windows 桌面的计时器，日常收益立刻兑现 |
| 练手 / 学技术 | **值得**，但要认清是练习 | 番茄钟是最小可用的完整产品形态，适合练桌面端、本地存储、统计可视化 |
| 做成产品卖钱 | **不建议** | 移动端已饱和（头部均分 4.78–4.91，靠评分拉不开差距）；功能已被做尽；免费替代品（Pomofocus 免费版功能已够用、带桌面端、Premium 仅 $18/年）质量太高；变现要么踩订阅信任坑，要么打不动付费意愿 |

**一句话：作为个人工具值得做，作为商业产品不值得做。**

## 二、这个品类真正没被满足的四个点（合并两边的证据）

1. **PC / Windows 桌面端是真空**
   番茄ToDo、Forest、小鸡专注、椅子上有猫都没有原生 Windows 客户端；潮汐有 5 星用户在评论里主动求"能否出一个电脑版"；Pomofocus 有 Windows 包但只是免费版（带广告）的裸打包，没做桌面端该有的东西。而目标用户的真实工作场景恰恰在电脑前。

2. **订阅信任是品类级雷区**
   潮汐 1 星评论几乎全在骂"7 天试用直接扣 198 元年费""强制绑定免密支付""扣费无提示""退款被拒、客服失联"；滴答也有"续费无提示直接扣 168"。这不是产品缺陷，是信任崩塌——**"一次性买断或免费，绝不自动续费"本身就是卖点**。

3. **统计回答不了"我的时间去哪了"**
   主流只给总时长 + 热力图 + 番茄数；滴答用户实测投诉"桌面专注时长和实际不符，8 小时 14 分只显示 7 小时多"。没有任务/项目维度，看不出哪类活最费时间、什么时候效率最高、什么最容易打断。

4. **复杂化正在杀死老用户**
   Forest（买断改会员、操作变繁琐）、小日常（功能变多+广告变多）、滴答（信息架构过载）被同一条评论骂。**"少而准"在这个时间点反而是稀缺品**。

补充一条来自国际部分的共性：**结束提醒不可靠**——手机上锁屏后只剩一条通知，评测直接点名"几乎是很多番茄钟软件的通病"。桌面端恰好能解决它（置顶窗 + 声音 + 全屏闪烁）。

## 三、边界：什么不做

- 不做游戏化（种树/养猫/小鸡）——赛道被 Forest、小鸡专注占死。
- 不做移动端 App 冲榜——商店位置和心智能占死。
- 不做纯网页版——Pomofocus 免费版可用度已很高、还带桌面端，正面撞不上。
- 不做待办清单 / 日历 / 健康同步 / 白噪音商店 / 社交排行榜——每加一项就往"复杂化被骂"的路上走一步。
- 不做自动续费——哪怕以后收费，也只做一次性买断。

## 四、第一版（v0.1）建议范围

**定位：Windows 桌面常驻的专注计时器，零账号、纯本地、只解决「按下去、到点必被叫醒、事后能看清时间去哪了」三件事。**

必须有的（P0）：

1. 托盘常驻 + 全局快捷键开始/暂停（不切窗口就能开番茄）
2. 25/5 默认循环，可自定义时长与轮数，自动进入下一段
3. **结束强提醒**：置顶窗 + 声音 + 窗口闪烁（解决"提醒不可靠"）
4. 每段结束强制记一行：任务名 + 是否被打断（可选打断原因），一次输入不超过 3 秒
5. 本地 SQLite 存全部数据，支持导出 CSV，零账号零云
6. 三张统计图：一天内分布、一周趋势、打断原因排行

可以后置的（P1）：桌面全屏遮罩/锁指定程序（"强制力"，桌面端没有系统级拦截能力，得自己做）、标签分类、深色主题、开机自启。

明确不做：见第三节。

## 五、技术选型建议（等用户确认后再定死）

- **桌面壳**：Tauri（体积小、内存占用低，适合常驻托盘）；如果团队更熟 Node 生态，Electron 也可接受，代价是包更大。
- **界面**：React + TypeScript，图表用轻量库（不用仪表盘级方案）。
- **存储**：本地 SQLite（Tauri 走 sqlite 插件；Electron 走 better-sqlite3）。
- **提醒**：系统通知 + 自绘置顶窗（Windows 通知本身不可靠，必须叠一层自绘）。
- **分发**：单个安装包，免账号，不做自动更新服务器（第一版手动更新即可）。

## 六、后面几轮怎么排（供用户点头后执行）

- 第 2 轮：定形态与技术栈 → 出 v0.1 功能清单 + 界面草图（我出，小M 复核可行性）

- 第 5 轮：打包成可双击安装的 exe，做一轮自用验收（连续用 3 天，记录哪里别扭）
- 第 6 轮：按自用反馈砍功能（这一步最重要，砍比加重要）

## 八、本次调研没覆盖到的（诚实标注）

- 安卓端竞品（Google Play 抓取失败，小M 以 iOS 中国区为准）。
- 小红书 / 知乎 / 少数派的用户吐槽（本轮搜索后端失效）。
- Forest Plus、番茄ToDo、小鸡专注、小日常、椅子上有猫的具体订阅价格（需 App 内购列表人工核对，本文一律不做估算）。
- 真实用户访谈样本（目前全部是公开评论证据，没有一对一访谈）。
