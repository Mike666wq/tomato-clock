## 一、执行摘要

1. **这个品类的功能已经做完了，没有护城河。** 番茄 + 白噪音 + 统计热力图 + 小组件 + 待办 + Health 同步 + 手表端 + 悬浮窗，移动端头部全部具备，GitHub 上还有几百个开源实现，一周能做出一个能用的。
2. **供给极度饱和，商店位置已占死。** iOS 中国区：番茄ToDo 94.3 万条评价、小日常 55.3 万、Forest 25.9 万、潮汐 15.3 万、滴答清单 15.0 万；头部均分全部 ≥4.78，评分无法再拉开差距。Forest 官方口径全球 6000 万用户。
3. **差异化只剩三条路**：强制力（能不能真的拦住你）、数据洞察（能不能告诉你以前不知道的事）、工作流深度绑定。中间的"比免费版多一点统计"最难赚钱。
4. **P0 痛点是订阅信任危机。** 潮汐 1 星评论几乎全部在骂"试用默认勾选年费→直接扣 198""强制绑免密支付""扣费无提示""客服不回复"；滴答清单也有"续费无通知直接扣款 168"。
5. **P0 痛点是桌面端与强制力的真空。** 番茄ToDo / Forest / 椅子上有猫均无原生 Windows 客户端；潮汐用户公开求 PC 版。而"拦截其他 App 打开"是 iOS 的系统级能力，手机端独有，桌面端想强制必须自己定义阻断对象。
6. **P1 痛点是统计太浅。** 主流只给总时长 + 热力图 + 番茄数；滴答清单用户实测投诉"实际 8 小时 14 分，桌面只显示 7 小时多"。
7. **P1 痛点是复杂化正在杀死老用户。** Forest（买断改订阅 + 操作繁琐）、小日常（功能变多 + 广告变多）被同一条评论骂："用户使用软件是为了高效"。
8. **免费替代品太强。** Pomofocus 免费版 + 手机自带计时器 + 手表计时器，已覆盖"我就想按个 25 分钟"的需求。真正压死后来者的不是"免费版带广告"，而是**免费版把任务级统计、预估完成时间、Todoist 集成、Webhook 全给了**——底价被拉到接近零。
9. **结论（分目的看）**：自己用 / 练手 → **值得做**；当商业产品卖 → **不建议**，除非能具体回答强制力 / 洞察 / 工作流绑定里的至少一条。
10. **如果要落地，第一版应克制在**：Windows 桌面常驻 + 零账号纯本地 + 结束强提醒 + 每次番茄强制记一行"做了什么 + 被打断几次" + 只做三张统计图；明确不做待办、日历、白噪音商店、社交、排行榜。
11. **一句话**：作为个人工具值得做，作为商业产品不值得做——除非你要做的其实不是番茄钟。

### 2.3 三种典型路线与各自的死法

| 路线 | 代表 | 优点 | 死法 |
|---|---|---|---|
| 极简计时器 | Pomofocus、Pomotroid、网页版 | 门槛最低 | 用完就走，没有留存理由，很难收钱 |
| 游戏化 / 情绪价值 | Forest、Flora、椅子上有猫、小鸡 | 有留存、有分享欲 | 本质是装饰，功能并未更强；且这条赛道已被占死 |
| 大而全效率套件 | 滴答清单、Focus To-Do、Toggl | 能收订阅费 | 重；光为计时器装一整套，心理成本高；番茄功能被淹没 |

**空白点：几乎没有一款是「小而专、但能真正黏住人」的。** 要么太轻（无留存），要么太重（无必要）。

## 三、用户痛点分级

> 每条附一手证据与来源链接。证据来源分两类：① App Store 用户评论原文（iTunes Reviews RSS API 实拉）；② 评测 / 社区横评（肥鱼抓取）。

### P0 — 订阅信任危机（品类级通病）

| 证据 | 来源 |
|---|---|
| "试用7天后一下子就自动续订包年了，你包月我都理解！" / "冲着宣传的7天免费试用，操作后立即被扣除198元年费" | [潮汐 App Store 评论](https://apps.apple.com/cn/app/id1077776989) |
| "一定要选续费方式才能进app内部…强制绑定免密支付一进去就被扣了198块，还我钱" | 同上 |
| "无缘无故被扣了198元，没有任何提示" / "退款被拒绝，有没有天理谁能管管" / "多次催促却始终没有明确的处理进度" | 同上 |
| "在没用提醒的情况下给我扣了168就算了" / "续费前没有通知提醒，直接就扣款了" | [滴答清单 App Store 评论](https://apps.apple.com/cn/app/id626144601) |
| "无良收费软件。第一次使用，可以免费创建2个习惯。结果一创建就要买卡。" | [番茄ToDo App Store 评论](https://apps.apple.com/cn/app/id1242689729) |

**含义**：无品牌背书的新产品一旦做订阅，会直接继承这个坑。这是品类里最贵的一笔学费。

### P0 — 桌面端缺位 + 强制力天花板

| 证据 | 来源 |
|---|---|
| "能否出一个电脑版的，平时用电脑播放的次数更多…电脑下载手机版还不适配"（5 星用户的主动请求） | [潮汐 App Store 评论](https://apps.apple.com/cn/app/id1077776989) |
| 番茄ToDo / Forest / 椅子上有猫 / 小鸡专注 均无原生 Windows 客户端（Forest 仅有浏览器扩展） | 各产品商店页 |

| "番茄钟最大的敌人就是手机本身；只有 Forest 这类做了应用拦截/翻转屏幕，多数产品只做「提醒」不做「拦截」" | [guozh.net 横评](https://guozh.net/best-pomodoro-apps/) |

**关键技术约束**：iOS 的"拦截其他 App 打开"是操作系统级能力（Forest「白名单需 iOS 16+」、番茄ToDo「学霸模式拦截其他 App 打开」、小鸡专注「锁定其他应用」），**手机端独有**。桌面端要实现强制力，只能自己定义阻断对象：全屏遮罩、锁指定程序、可选浏览器屏蔽等。

## 四、空白点

按"未被满足的程度 × 可进入的难度"排序：

1. **Windows 桌面端原生专注工具**（几乎无人认真做）
   番茄ToDo / Forest / 椅子上有猫 / 小鸡专注 都没有原生 Windows 客户端；潮汐用户公开求 PC 版；Pomofocus 有桌面包，但只是免费版（带广告）的裸打包，无任何差异化设计。
2. **桌面级强制力**
   手机端靠 OS 权限，桌面端目前没有成熟方案。可自行定义：全屏遮罩、锁指定程序、可选浏览器屏蔽、强制全屏专注模式。
3. **任务 / 项目维度的诚实复盘**
   主流只给总时长与热力图；"什么时段效率高""哪类任务总被打断""今天时间到底花在哪"无人系统性回答，且已有产品统计不准（滴答 8h14m → 7h）。
4. **零账号、纯本地、可自持的数据结构**
   小日常"不开 iCloud 历史数据清空"证明云绑定型产品做不好本地用户的信任；纯本地 + CSV 导出是被反复提的需求。
5. **克制的交互**
   Forest、小日常、滴答全被同一句话骂过。三步开跑、复杂度藏进设置，是可以做到但大家都没做到的。
6. **不靠订阅的商业结构**
   一次性买断或完全免费，把"信任"变成自己的卖点，而不是像潮汐那样成为自己的坟头。

## 五、结论与边界

### 5.1 值得做的条件（同时满足才建议立项）

1. **形态选 Windows 桌面原生**，而非移动 App、也非纯网页。
2. **定位为个人生产力工具**，而非游戏化专注 App（种树 / 养宠赛道已占死）。
3. **差异化落在三件事**：任务/项目维度复盘、桌面级干扰阻断、零账号纯本地 + 不订阅。
4. **有明确的第一用户群**，能形成真实反馈闭环。
5. **接受它首先是自用工具**。按个人工具投入，产出是每天真用得上的东西。

### 5.2 不值得做的条件（出现任意一条即建议放弃或改方向）

1. 想做"又一个游戏化番茄钟"——赛道被 Forest / 小鸡 / 猫 / 我的番茄占死，且新品评分无法超过 ≥4.78 的存量。
2. 想做移动端 App 冲榜——94 万 / 55 万 / 25 万评分的头部已占死商店位置与用户心智，获客成本远高于产品价值。
3. 想做纯网页版——Pomofocus 免费版功能已够用（带广告，Premium $18/年去广告）、可导出 CSV、还带桌面客户端，替代品太充足。
4. 想靠订阅变现且无差异化——无品牌背书时踩 P0 信任坑几乎必翻车。
5. 指望"统计做得漂亮"取胜——统计在所有产品里长得一样，做漂亮不构成壁垒。

### 5.3 三种目的下的结论

| 目的 | 结论 | 边界 |
|---|---|---|
| 自己用 | **值得** | 半天到两天；本地、零账号、零广告、钉在桌面上；只追求"比 Pomofocus 少干扰"，别追求功能全 |
| 练手 / 学技术 | **值得** | 心里要清楚这是练习，番茄钟本身没有可挖的商业价值 |
| 做成产品卖钱 | **不建议** | 除非能具体回答强制力 / 数据洞察 / 工作流绑定里的至少一条，并能回答"凭什么让人离开免费的 Pomofocus / Forest" |

### 5.4 一句话

> **这个品类的功能已经做完了，剩下没被做的是「形态」和「信任」，不是「功能」。**
> 作为个人工具值得做，作为商业产品不值得做——除非你要做的其实不是番茄钟。
